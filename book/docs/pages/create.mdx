# Create Game

PAVED supports three game creation paths from the mode dialog:

1. `Default` uses mode defaults.
2. `Template` uses a specific `templateId`.
3. `Custom (Advanced)` uses an explicit config payload.

`Custom (Advanced)` is only shown when `CONFIG_CREATE_V1` is enabled in the client environment.

## Validation

When creating with `Template` or `Custom (Advanced)`, invalid inputs are rejected before dispatch:

1. Invalid template ids are blocked.
2. Invalid custom fields (for example, `durationSeconds <= 0`) show field-level errors.
3. Private custom games require a non-zero `accessRoot`.

## Runtime Behavior

On successful creation, the selected config is snapshotted on the game at spawn time so gameplay uses a stable config for the full session.
