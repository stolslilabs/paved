Draco decoder (glTF build) for `DRACOLoader`, self-hosted: copied unchanged from `three@0.186.1`, `examples/jsm/libs/draco/gltf/` (`draco_decoder.js`, `draco_decoder.wasm`, `draco_wasm_wrapper.js`). Source: https://github.com/google/draco (branch `gltf_2.0_draco_extension`). Licence: Apache-2.0 (https://github.com/google/draco/blob/master/LICENSE), as three's `libs/draco/README.md` states; the minified files carry no header of their own. The renderer's `AssetLoader` loads them from `<basePath>/draco/`, only for a Draco-compressed model. Update them together with `three`.
